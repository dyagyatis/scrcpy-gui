# ⚡ Scrcpy GUI Flutter

Кроссплатформенный графический интерфейс для **Scrcpy** на базе **Flutter / Dart** (вдохновленный проектом GeorgeEnglezos/Scrcpy-GUI).

---

## 🌟 Возможности

- **Многопоточный Scrcpy Service**: одновременный запуск и управление несколькими подключенными Android-устройствами.
- **Поддержка Wi-Fi ADB**: прямое подключение по IP:Port + сопряжение с кодом для Android 11+.
- **Тонкая настройка видео/звука**: H.264, H.265/HEVC, AV1, OPUS, AAC, FLAC, RAW, битрейт, буферы.
- **Пользовательская геометрия окна**: произвольные размеры `--window-width` и `--window-height`, координаты X/Y на экране.
- **Быстрые пресеты в 1 клик**: Стандарт, Игровой (120 FPS), Макс. качество, Эко, Скрытый экран, Только звук.
- **Инструменты ADB**: установка APK, передача файлов, навигация Android, перезагрузка.
- **Встроенные бинарники**: локальная папка `bin/` со всеми библиотеками Scrcpy v4.1 и ADB.

---

## 🚀 Запуск и сборка

### 1. Установка зависимостей:
```bash
flutter pub get
```

### 2. Запуск на Windows Desktop:
```bash
flutter run -d windows
```

### 3. Сборка исполняемого exe файла:
```bash
flutter build windows --release
```
Готовый исполняемый файл будет собран в: `build\windows\x64\runner\Release\scrcpy_flutter_gui.exe`
